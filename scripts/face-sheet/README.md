# face-sheet — 아이가 그리는 얼굴 파츠 시트

종이에 인쇄해 칸마다 얼굴 파츠를 그리고, 사진을 찍으면 파츠마다 투명 PNG가 나온다. 아이가 그린 색을 그대로 쓴다. [얼굴-설계.md](../../얼굴-설계.md) 8절의 "직접 그린 파츠"를 받는 입구다. 프런트엔드는 건드리지 않는다. 받은 파츠로 얼굴을 그리는 이미지 레이어는 그다음 단계다(8절).

## 쓰는 법

```bash
cd scripts/face-sheet && uv sync
```

```bash
uv run python -m sheet.render out/
```

`out/blank.pdf`(그릴 종이)와 `out/example.pdf`(지금 얼굴을 칸에 넣은 예시)가 나온다. A4로 **실제 크기(100%)** 인쇄. 맞춤 인쇄로 줄어도 추출은 되지만 파츠가 칸이 약속한 것보다 작게 그려진다.

그린 뒤 장마다 사진을 찍는다. 순서와 각도는 상관없지만 **모서리 마커가 4개 중 3개 이상** 나와야 한다. 그림자가 칸을 가로지르지 않게 찍는다. 그다음:

```bash
uv run python -m sheet.extract photos/*.jpg --out parts/
```

`parts/`에 파츠별 PNG, `parts.json`(파츠마다 얼굴 좌표계 400×400에서의 상자. 이미지를 이 상자에 맞춰 늘려 그리면 된다), `preview.png`(가만히·깜빡·아~·오~·생각 다섯 얼굴로 조립한 것)이 나온다. 안 그린 필수 칸은 마지막 줄에 나온다. 같은 장을 다시 찍어 넘기면 나중 사진이 이긴다.

## 시트

| 장 | 칸 | 얼굴에서 하는 일 |
| --- | --- | --- |
| 1. 얼굴 바탕 | `base` (선택) | 늘 그대로인 것: 볼·점·장식. 테두리 밖 눈금이 눈·입 자리를 알려 준다 |
| 2. 눈 | `eyes_open`, `eyes_half`(선택), `eyes_closed` | 두 눈을 한 칸에. 시선·깜빡임에서 두 눈은 늘 같이 움직인다 |
| 3. 말하는 입 | `mouth_a`(a), `mouth_ei`(e·i), `mouth_ou`(o·u), `mouth_m`(m), `mouth_nx`(n·x) | viseme 8종을 아이가 구분해 그릴 수 있는 5개로 묶었다 |
| 4. 표정 입과 눈썹 | `mouth_idle`, `mouth_listening`, `mouth_thinking`, `brows`(선택) | mood별 입. 눈썹은 한 칸에 둘을 그리면 가운데에서 잘라 `brows_left`·`brows_right`가 된다(생각 중엔 오른쪽 눈썹만 올라가므로) |

- **축척이 하나다.** 모든 칸이 얼굴 1단위 = 0.6 mm라서, 아이가 그린 크기 비율이 그대로 화면에 간다. 칸의 가운데(테두리 밖 눈금)가 그 파츠의 기준점이다(눈 쌍 200,168 · 입 200,268 · 눈썹 200,113).
- **칸 안에는 아무것도 인쇄하지 않는다.** 테두리·눈금·글자는 모두 칸 밖에 있고, 자르기는 테두리 1.5 mm 안쪽에서 한다. 그래서 안내선을 지우는 단계가 없다.
- 시트 정의는 [sheet/layout.py](sheet/layout.py) 하나다. 인쇄와 자르기가 같은 정의를 쓴다. 칸이나 장을 더하면(감정 세트 등) 둘 다 따라온다.
- 예시 시트의 입 모양은 [face_shapes.ts](../../frontend/src/face_shapes.ts)의 표를 **읽어서** 그린다(복사하지 않는다). 볼은 화면에선 16% 반투명이지만 종이에선 추출 문턱 아래라서 진하게 인쇄한다.

## 추출이 하는 일

1. ArUco 마커(DICT_4X4_50, id = 장×4 + 모서리)로 장을 알아내고, 마커 모서리로 호모그래피를 잡아 10 px/mm로 편다.
2. **조명 모델**: 칸 밖 빈 종이(여백·칸 사이)를 4 mm 격자로 표본 삼아 채널마다 2차 곡면을 맞춘다. 한 번 맞춘 뒤 그보다 어두운 표본(칸 밖 낙서)을 빼고 다시 맞춘다. 칸 안을 꽉 채워 칠해도 종이색을 칸 밖에서 가져오니 망가지지 않는다.
3. 사진을 종이색으로 나눈 뒤 **가장 어두운 채널이 흰색에서 얼마나 먼가**를 잉크 세기로 쓴다(0.10~0.30 사이를 알파 0→1). 노란색처럼 밝은 색도 파랑 채널이 낮아 잡힌다.
4. 0.8 mm² 미만 얼룩은 버린다. 알파를 되돌려 가장자리 색을 복원한다(`seen = α·ink + (1−α)`). 그래야 반투명 가장자리가 흰빛으로 바래지 않는다.
5. 잉크 영역으로 잘라 저장한다. 6 px/단위로, 키오스크(1.6 px/단위)의 약 4배다.

## 알아 둘 것

- **흰색은 투명이 된다.** 종이 흰색과 구별할 수 없다. 눈의 흰자 같은 건 화면 배경색이 비쳐 보인다. 그래서 얼굴 화면 배경은 밝아야 한다(8절).
- 연필·연한 색연필은 문턱 근처라 얼룩져 나온다. 굵은 사인펜이 가장 깨끗하다.
- 테스트([tests/test_roundtrip.py](tests/test_roundtrip.py))는 인쇄→촬영을 흉내 낸다. PDF를 래스터해 탁자 위에 비스듬히 놓고, 따뜻하고 고르지 않은 조명·노이즈·블러를 입힌다. 그런 다음 예시 시트에서는 지금 얼굴 파츠가 제자리(±2.5 단위)에 제 색으로 나오는지, 빈 시트에서는 파츠가 0개인지 본다.

```bash
uv run pytest
```
