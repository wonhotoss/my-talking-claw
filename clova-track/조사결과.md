# 조사결과

2026-08-15 웹 조사 종합. 출처는 문서 하단.

## 1. 배경 — 왜 응답 품질이 낮은가

네이버가 **클로바 사업을 철수 중**이다. 서버·모델이 방치·축소되면서 품질이 하락했다. 이것이 이 프로젝트의 전제다: 클로바 백엔드는 개선될 리 없고, 오히려 **언제든 꺼질 수 있는 시한부 인프라**다.

클로바 EOL 타임라인:
- **2023-03-30** LINE 계열 기기용 CLOVA Assistant 서비스 종료, 2023-05-09 등록 스킬 채널 일괄 삭제. LINE 개발자 콘솔(`clova-developers.line.biz`)은 현재 **도메인 자체가 DNS에서 해석되지 않음**(완전 사망).
- **스피커(웨이브·프렌즈 등) 판매·AS 종료.**
- **2026-04** ClovaX·큐(Cue:) 종료. 언론은 네이버의 "클로바 사업 철수 수순"으로 보도.
- 한국 소비자용 스피커 클라우드는 **아직** 동작(사용자가 현재 사용 중)하나, 위 흐름상 시한부.

## 2. 동작 아키텍처 — 후킹 지점

```
[스피커] --(CIC, TLS)--> [네이버 클라우드: STT→추론→TTS] --(CEK)--> [서드파티 확장 서버]
```

- **스피커 ↔ 클라우드 = CIC (Clova Interface Connect).** 프로덕션 엔드포인트 `prod-ni-cic.clova.ai`. Alexa AVS류의 클라이언트↔클라우드 프로토콜이며, 네이버가 서드파티 기기 제작용으로 **문서를 공개**했다(github `naver/clova-client-developer-guide`). → 우리가 프로토콜을 (상당 부분) 안다는 뜻.
- **클라우드 ↔ 확장 = CEK (Clova Extension Kit).** 콘솔은 `developers.naver.com/console/clova/cek`. 확장은 "호출명"으로 부르는 별도 스킬일 뿐, **기본 어시스턴트를 대체하지 못한다.** 커뮤니티 선례 `huimang2/clova`(홈어시스턴트↔CEK)가 이 경로를 쓰지만 "사전 정의된 스마트홈 기기 액션만" 처리, 자유 발화 라우팅 불가.

→ "아무 말이나 → 내 추론 → 내 음성"을 하려면 **가운데 클라우드 구간을 가로채거나(MITM), 기기의 두뇌를 갈아끼워야** 한다. CEK로는 불가능.

### CEK 콘솔 라이브 확인 실패 (한계)

Claude Code 환경에서 `developers.naver.com`·`web.archive.org`가 모두 정책 차단이고 연결된 Chrome도 없어, CEK 콘솔의 신규 등록 가능 여부를 **라이브로 확정하지 못함**. 다만 위 EOL 정황(사업 철수, LINE 쌍둥이 플랫폼 사망)상 신규 등록은 닫혔거나 시한부로 추정. 확정하려면 사용자가 네이버 로그인 후 콘솔에서 "확장 만들기" 생존 여부를 2분 내 확인 가능 — 단 실익이 없어 권장하지 않음(→ [경로분석.md](경로분석.md) C 폐기).

## 3. 판을 바꾸는 사실 — 기기 = 안드로이드

- **클로바 웨이브 = Qualcomm APQ8009 = 스냅드래곤 210.** 안드로이드폰용 애플리케이션 프로세서 → 사실상 AOSP 안드로이드 머신(2017년경). 모델별 SoC는 상이(프렌즈/데스크/클락/램프는 확인 필요).
- 스냅210(MSM8909/APQ8009) 계열은 **EDL(9008) 모드**(Sahara+Firehose, XML over USB)로 펌웨어 덤프/플래시 가능. 커뮤니티 firehose 로더 수집·`bkerler/edl` 툴 존재. 부트로더 언락·루팅 선례 풍부.
- 안드로이드이므로 **TLS 인증서 피닝은 Frida로 런타임 우회** 가능 — 원래 네트워크 후킹(A)의 최대 관문이던 "펌웨어에 CA 심기"가 불필요. 표준·현역 기법(2026 가이드 다수).

→ 결과적으로 A(네트워크 후킹)와 B(하드웨어 이식)가 **하나의 안드로이드 리버싱 경로로 통합**된다.

## 4. 재사용 가능한 자산

- **네이버클라우드(NCP) CLOVA CSR**(STT)·**CLOVA Voice**(TTS) 유료 API는 **생존** — 최고 수준 한국어 품질. 리퍼포즈 시 자체 스택의 한국어 STT/TTS로 그대로 활용 가능(로컬 Whisper/Piper 대안).
- **CIC 프로토콜 문서**(`naver/clova-client-developer-guide`) — 앱 후킹/MITM 경로에서 응답 포맷 구현에 활용.
- **`huimang2/clova`** — CEK 연동 선례. 콘솔 등록 절차·엔드포인트(`prod-ni-cic.clova.ai`) 등 참고 정보.
