# 클로바 분해·리버싱 자료 조사 (2026-09-12)

"클로바를 분해 분석한 프로젝트가 인터넷에 있나" 웹조사 결과. 결론: **있다. 그중 프렌즈를 실물 chip-off한 학술논문이 우리 프로젝트의 최대 미확정(프렌즈 SoC/OS)을 상당 부분 해소한다.**

## ★ 1순위 — 프렌즈 실물 chip-off 학술논문 (아주대 손태식 연구실 + 대검찰청)

### (1) Digital Forensic Practices and Methodologies for AI Speaker Ecosystems
- Jo, Shin, Kim, Yoo, Kim, Kang, Jin, Oh, Na, Shon. *Digital Investigation* 29 (2019) S80–S93. DFRWS 발표. 오픈액세스.
- PDF: https://dfrws.org/wp-content/uploads/2019/11/2019_USA_paper-digital_forensic_practices_and_methodologies_for_ai_speaker_ecosystems.pdf
- **분석 대상 = Clova FRIENDS (SALLY)** — Table 2의 clientName=FRIENDS, deviceName=SALLY. 우리 기기(브라운)와 동일 모델군.
- 확정된 하드웨어/소프트웨어:
  - **OS: 안드로이드** (리눅스 기반, EXT4 기본 파일시스템). "Android operating system is used in all the AI speakers examined."
  - **플래시: Micron MT29TZZZ8D5JKEZB, MLC NAND 기반 저전력, 8GB.** (eMMC/eMCP급 패키지) — 전문업체가 chip-off로 적출·이미징.
  - **파티션(EXT4):** cache 1.0GB(업데이트/update.zip), system 1.2GB(APK·.so·설정, 355MB 사용), userdata 4.8GB(개인정보·설정, 최우선 분석 대상) + boot/backup/복사본. 3개 주파티션이 총 용량 96%(7,809,925,315 B).
  - 디렉터리: /system, /data, /misc, /dalvik-cache.
  - 앱 패키지: `com.naver.nozzle` (v2.11.0).
  - 온디바이스 아티팩트: `BluetoothInfoKey`(.xml, 폰 MAC·기기타입·사용자명), `UseInfoKey`(.xml, 위치·주소), `notification_log`(.db SQLite, event_time_ms로 사용기간 추정, friendsettings/friendsnocker/friendssound 패키지 호출), `nvoice_<hash>.mp3`(음성 응답).
  - 클라우드: **CIC = prod-ni-cic.clova.ai**, 인증 = auth.clova.ai. access token 유효 **150일**. 서버에 **최근 명령 100개** JSON 저장(앱 UI로 조회).
- **의미:** 프렌즈가 **범용 안드로이드 AP**임이 확정 → **엔드스테이트1(리퍼포즈: 클로바앱 정지+내 어시스턴트 APK 탑재) 실현 가능**, 라파 하드웨어 이식 폴백은 불필요.
- **한계:** 이 논문은 **플래시만** 마킹 판독하고 **SoC(AP) 정확 모델명은 미기재.** 웨이브=APQ8009(스냅210) 확정이라 프렌즈도 동급 Qualcomm 가능성이 있으나 미확인 → 케이스 열어 AP 칩 마킹 판독은 여전히 필요.

### (2) Certificate Injection-Based Encrypted Traffic Forensics in AI Speaker Ecosystem
- 2020, ScienceDirect S2666281720302596 (같은 연구실).
- 클로바 등에 **인증서를 주입해 클라우드 암호화 트래픽(CIC)을 복호화**하는 5방법:
  1. 스피커 이미지를 안드로이드폰에 포팅
  2. QEMU 에뮬레이션으로 구동
  3. 앱 취약점 익스플로잇
  4. HW 인터페이스로 플래시 재기록
  5. 플래시 리워크·업데이트
- wpa_supplicant.conf 수정, 펌웨어 자동추출툴 언급.
- **의미: 우리 엔드스테이트2/3(CIC MITM·인증서 피닝 우회)의 실전 로드맵.** frida 런타임 우회 대신 이미지 레벨 인증서 주입이라는 대안 경로를 제시.
