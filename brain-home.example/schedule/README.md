# schedule/

두뇌가 "나중에 할 일"을 JSON 파일로 쓰는 곳. 게이트웨이의 스케줄러가 몇 초마다 훑어서
`at`이 지난 파일을 실행한다.

- `{"at": "2026-11-01T15:14:00", "say": "…"}` → 그 문장을 그대로 말한다 (`POST /api/push`, 에이전트 홉 없음)
- `{"at": "2026-11-01T19:00:00", "prompt": "…"}` → 두뇌에게 새 턴을 시키고 그 답을 말한다
- `at`에 시간대가 없으면 기기의 현지 시각
- 실행된 파일은 `done/`, 읽을 수 없는 파일은 `failed/`로 옮겨진다(로그에 남는다)
- 취소 = 파일 삭제

이 README 자체는 `*.json`이 아니라 무시된다.
